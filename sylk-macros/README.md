# sylk-macros

Procedural macros for [sylk](https://crates.io/crates/sylk): `#[derive(Pack)]`, `#[register]`, `#[collect]`, `#[resource]`, `#[server]`, `#[get]`, `#[post]`, `#[put]`, `#[delete]` and `#[patch]`.

sylk re-exports every one of them in every mode, with no feature needed, so this crate is not meant to be a direct dependency. Usage is covered in the [sylk documentation](https://docs.rs/sylk).
